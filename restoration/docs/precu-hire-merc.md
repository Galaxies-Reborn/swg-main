# PRE-CU Hire a Merc

## Player surface and engine boundary

The stock mission browser tabs are client-authored and expose no server script
hook for adding a tab. Combat mission terminals therefore expose the exact
localized radial **Hire a Merc**, which opens a tab-like localized roster list
titled **Hire a Merc**. The stock mission browser is not replaced.

The terminal script is inherited from `terminal_mission.tpf` and then uses a
fail-closed allow-list. It accepts only generic destroy, Imperial combat, and
Rebel combat mission terminal templates. `intArtisan`, `intScout`,
`intEntertainer`, `intBounty`, and `intNewbie` role terminals are explicitly
excluded even when a buildout uses the generic template.

## Provisional balance constants

- Contract duration: 2 hours.
- Cost: 5,000 credits plus 100 credits per bounded combat level.
- Mercenary level range: 1 through 100.
- Ability tiers unlock at levels 1, 25, 50, and 75.
- One active mercenary per character; normal party cap remains eight.

These values are centralized in `script.library.mercenary` for the future
balance pass requested by design.

## Roster and scaling

The roster covers 18 ground-combat families: Novice Brawler, Novice Marksman,
Novice Medic, Bounty Hunter, Carbineer, Combat Medic, Commando, Creature
Handler, Doctor, Fencer, Pikeman, Pistoleer, Rifleman, Ranger, Smuggler, Squad
Leader, Swordsman, and Teras Kasi Artist. Doctor and Ranger are included as
ground support hybrids. Crafting, entertainer, politician, and space-pilot
professions are excluded.

`create.createCreature` receives the player's bounded PRE-CU encounter level.
Its existing PRE-CU level profile scales HAM, accuracy/defense, armor, and the
actual equipped primary/secondary weapon damage. The mercenary controller adds
level-gated role abilities and medical routines; the stored weapon-quality
value is the same bounded level for inspection and later balance tuning.

## Party, reward, and AI invariants

Mercenaries are enrolled through the native pet group invite/accept commands.
`setMaster` is not treated as proof of group membership. The hire becomes
active only after the player and NPC resolve to the same group and the native
group-member script is present. Failed enrollment rolls back the master,
group, player pointer, and spawned NPC before refunding the debit.

Dynamic mission credits are distributed by `mission_base` through
`group.getPCMembersInRange`; that helper filters every recipient with
`isPlayer`. The mercenary is a real non-player group member, so it appears in
the party but cannot dilute the player credit pool. The documentary
`precu.hireMerc.noMissionCredit` marker is also set on every hire.

The controller suppresses ambient saw-attack reactions. It engages only while
the current party leader is in combat. It directly assists that leader's
combat target; follow-on targets must match both the same `creatures.tab` name
and the same mission/lair/POI anchor. Unanchored wilderness targets cannot
bleed into an anchored mission spawn. Medic, Combat Medic, Doctor, and Squad
Leader variants heal damaged primary pools of nearby player party members.

## Vehicles

When the party leader mounts, the controller first checks the leader's mount
for an available passenger seat and uses the native group passenger permission
check. Only when no usable seat exists does it create a nonpersistent
speederbike fallback. The fallback deliberately has no vehicle control device,
is destroyed on dismount/cleanup, and is never stored. When the leader
dismounts, the mercenary dismounts immediately and destroys its fallback.

## Accounting and client asset

Payment callbacks validate the full named-account envelope (return code,
player, null target, account, amount, total, and custom nonce/quote). The nonce
is never automatically expired because bank callbacks can arrive late.
State transitions make duplicate success callbacks inert. Spawn or group
failure queues an authenticated refund; exhausted retries keep the operation
locked and emit a Customer Service reconciliation record rather than allowing
a second debit or free spawn.

TRE input: `string/en/precu_hire_merc.stf`

The bounded generator is
`restoration/scripts/New-PrecuHireMercStringTable.ps1`; use `-Check` to verify
the generated bytes without rewriting them.
